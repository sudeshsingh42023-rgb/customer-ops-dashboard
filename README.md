# Project 2: Data-Driven Customer Operations Insights Dashboard

**Files:**
- customer_ops_data.csv — 1,200-row synthetic operational dataset (region, channel, category, agent, SLA, CSAT, escalation)
- analysis_queries.sql — 9 SQL queries (KPI summary, weekday escalation, SLA breach by category, FCR by category, agent leaderboard, monthly trend)
- Customer_Ops_Dashboard.xlsx — 3-sheet Excel workbook: Dashboard (KPI cards + 3 charts, all formula-driven), Agent Performance (ranked leaderboard), RawData (full dataset as a table)
- Insights_Memo.docx — business insights memo with 5 findings and recommendations

**Resume bullets (pick 1-2):**
- Built a Power BI/Excel-style KPI dashboard analyzing 1,200 customer service tickets across 4 regions and 4 channels; surfaced a 29.6% Monday escalation spike vs. 9-18% on other days and recommended staffing changes
- Wrote SQL queries to quantify First Contact Resolution (69%), SLA compliance (70.8%), and channel efficiency (Email tickets took ~2x longer than Chat), delivering 5 data-backed recommendations to operations leadership
- Identified the bottom 5 of 25 agents by FCR% (60.9-63.4% vs. 69% team average) and proposed a targeted coaching plan
